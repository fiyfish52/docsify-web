## 语法

> 打印输出
1. 输出普通参数 

```
bms_output.put_line('参数名'||paramName);
```

2. 输出时间类参数
注意是TO_CHAR

```
dbms_output.put_line('开始时间'||TO_CHAR(startDATE, 'DD-MON-YYYY HH24:MI:SS'));|
```
