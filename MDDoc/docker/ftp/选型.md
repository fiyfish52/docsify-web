### **1. FTP（File Transfer Protocol）**

- **协议类型**：标准网络协议（基于 TCP，端口 **21** 控制连接，**20** 数据连接）。
- **安全性**：
  - ❌ **明文传输**（用户名、密码、文件内容均未加密）。
  - 易受中间人攻击（MITM）和数据窃听。
- **认证方式**：用户名/密码。
- **传输模式**：
  - **主动模式（PORT）**：服务器主动连接客户端（可能被防火墙拦截）。
  - **被动模式（PASV）**：客户端连接服务器（更常用）。
- **典型工具**：
  - 命令行：`ftp`（Linux/Windows）、`lftp`。
  - 图形工具：FileZilla、WinSCP。
- **适用场景**：
  - 内网环境或对安全性无要求的临时文件传输。
  - 遗留系统支持（如老旧设备）。

------

### **2. SFTP（SSH File Transfer Protocol）**

- **协议类型**：基于 **SSH（Secure Shell）** 的扩展协议（默认端口 **22**）。
- **安全性**：
  - ✅ **全加密传输**（包括认证和文件内容）。
  - 使用 SSH 密钥或密码认证，支持公钥基础设施（PKI）。
- **特点**：
  - 单一连接（无需额外数据端口）。
  - 支持断点续传、文件权限管理、符号链接操作。
- **典型工具**：
  - 命令行：`sftp`（内置在 SSH 中）、`scp`（简单文件拷贝）。
  - 图形工具：FileZilla（需配置 SSH）、WinSCP。
- **适用场景**：
  - 需要高安全性的文件传输（如云服务器管理）。
  - 跨防火墙环境（仅需开放 SSH 端口）。

------

### **3. vsFTP（Very Secure FTP Daemon）**

- **本质**：一个 **FTP 服务端软件**（不是独立协议），专注于安全性。

- **支持的协议**：

  - 默认提供 **FTP** 服务（可配置为 **FTPS**，即 FTP over SSL/TLS）。
  - ❌ **不原生支持 SFTP**（需依赖 SSH 服务如 OpenSSH）。

- **安全性增强**：

  - 支持 **FTPS**（显式 `FTPES` 或隐式 `FTPIS`）。
  - 匿名访问控制、用户权限隔离、日志审计。

- **典型配置**：

  plaintext

  ```
  # /etc/vsftpd.conf
  anonymous_enable=NO
  local_enable=YES
  write_enable=YES
  ssl_enable=YES  # 启用 FTPS
  ```

- **适用场景**：

  - 需要 FTP 协议但需增强安全性的场景（如企业内部文件共享）。
  - 兼容传统客户端，同时支持加密（FTPS）。

------

### **对比总结**

| **特性**       | FTP                    | SFTP                 | vsFTP（FTP/FTPS）         |
| :------------- | :--------------------- | :------------------- | :------------------------ |
| **协议基础**   | 独立协议（RFC 959）    | 基于 SSH（RFC 4253） | FTP 服务端软件            |
| **加密**       | ❌ 明文                 | ✅ 全加密（SSH）      | ✅ 可选（FTPS）            |
| **端口**       | 21（控制）+ 20（数据） | 22（SSH 端口）       | 21（FTP）或 990（FTPS）   |
| **防火墙友好** | 被动模式较友好         | ✅ 单一端口           | 被动模式需开放额外端口    |
| **典型工具**   | FileZilla, `ftp` 命令  | `sftp` 命令, WinSCP  | vsftpd, ProFTPD           |
| **适用场景**   | 内网/临时传输          | 安全传输（云服务器） | 需兼容传统 FTP 的安全场景 |

------

### **如何选择？**

1. **必须加密** → 优先选择 **SFTP**（SSH 原生支持）。
2. **兼容传统 FTP 但需安全** → 使用 **vsFTP + FTPS**。
3. **仅内网/测试环境** → 普通 FTP（简单快速）。

------

### **附：FTPS vs SFTP 的区别**

- **FTPS**：FTP 协议 + SSL/TLS 加密（需配置证书，使用端口 990）。
- **SFTP**：基于 SSH 的文件传输协议（端口 22，无需额外配置加密）。

> **推荐**：现代环境中优先使用 **SFTP**，避免 FTP 的安全风险。
