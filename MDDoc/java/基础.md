## 注解

Java 注解（Annotation）是一种元数据形式，用于为代码提供附加信息，这些信息可以被编译器、运行时环境或框架读取和处理。以下是 Java 注解的全面解析：

### **一、注解基础**

#### 1. 内置注解

Java 提供了一些内置注解：

- **`@Override`**
  表示方法重写父类或接口的方法，编译器会检查方法签名是否正确。

  ```
  @Override
  public String toString() { return "Hello"; }
  ```

- **`@Deprecated`**
  标记方法/类已过时，使用时编译器会警告。

  ```
  @Deprecated
  public void oldMethod() {}
  ```

- **`@SuppressWarnings`**
  抑制编译器警告（如未使用变量）。

  ```
  @SuppressWarnings("unused")
  private int unusedField;
  ```

- **`@FunctionalInterface`** (Java 8+)
  表示接口是函数式接口（只有一个抽象方法）。

  ```
  @FunctionalInterface
  public interface Runnable { void run(); }
  ```

------

#### 2. 元注解（Meta-Annotations）

用于定义注解的注解：

- **`@Target`**
  指定注解可以应用的位置（如类、方法、字段等）：

  ```
  @Target(ElementType.METHOD) // 只能用在方法上
  public @interface MyAnnotation {}
  ```

  可选值：`TYPE`, `FIELD`, `METHOD`, `PARAMETER`, `CONSTRUCTOR` 等。

- **`@Retention`**
  指定注解的生命周期：

  ```
  @Retention(RetentionPolicy.RUNTIME) // 运行时保留
  public @interface MyAnnotation {}
  ```

  可选值：

  - `SOURCE`：仅源码阶段（如 `@Override`）。
  - `CLASS`：编译时保留（默认值）。
  - `RUNTIME`：运行时保留（可通过反射读取）。

- **`@Documented`**
  表示注解应包含在 Javadoc 中。

- **`@Inherited`**
  表示子类可以继承父类的注解。

- **`@Repeatable`** (Java 8+)
  允许同一位置重复使用注解。

  ```
  @Repeatable(Authorities.class)
  public @interface Authority { String role(); }
  ```

------

### **二、自定义注解**

#### 1. 定义注解

```
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface LogExecutionTime {
    String value() default "defaultTask"; // 注解属性
    boolean enableLog() default true;
}
```

#### 2. 使用注解

```
public class Service {
    @LogExecutionTime(value = "calculate", enableLog = true)
    public void calculate() { /* ... */ }
}
```

#### 3. 处理注解（通过反射）

```
Method method = Service.class.getMethod("calculate");
if (method.isAnnotationPresent(LogExecutionTime.class)) {
    LogExecutionTime annotation = method.getAnnotation(LogExecutionTime.class);
    System.out.println("Task: " + annotation.value()); // 输出: Task: calculate
}
```

### **三、注解的常见应用场景**

#### 1. 框架集成

- **Spring**：
  `@Component`, `@Autowired`, `@RequestMapping` 等。

  ```
  @RestController
  public class MyController {
      @GetMapping("/hello")
      public String hello() { return "World"; }
  }
  ```

- **JPA/Hibernate**：
  `@Entity`, `@Table`, `@Column` 等。

  ```
  @Entity
  @Table(name = "users")
  public class User {
      @Id
      private Long id;
  }
  ```

#### 2. 代码生成（Lombok）

```
@Getter @Setter
public class User {
    private String name;
}
```

编译时自动生成 `getName()` 和 `setName()`。

#### 3. 校验（Validation）

```
public class User {
    @NotBlank(message = "Name不能为空")
    private String name;
}
```

#### 4. AOP（面向切面编程）

```
@Aspect
@Component
public class LogAspect {
    @Around("@annotation(LogExecutionTime)")
    public Object logTime(ProceedingJoinPoint joinPoint) throws Throwable {
        long start = System.currentTimeMillis();
        Object result = joinPoint.proceed();
        System.out.println("耗时: " + (System.currentTimeMillis() - start));
        return result;
    }
}
```

### **四、高级特性**

#### 1. 注解继承

默认情况下，子类不会继承父类的注解。使用 `@Inherited` 可让类注解被继承：

```
@Inherited
@Retention(RetentionPolicy.RUNTIME)
public @interface InheritableAnnotation {}

@InheritableAnnotation
public class Parent {}

public class Child extends Parent {} // Child 也会拥有 InheritableAnnotation
```

#### 2. 重复注解（Java 8+）

```
@Authority(role = "admin")
@Authority(role = "user")
public class MyService {}
```

#### 3. 类型注解（Java 8+）

注解可以用于泛型、类型转换等：

```
List<@NonNull String> list = new ArrayList<>();
```

------

### **五、注解 vs 接口**

| 特性     | 注解（Annotation）       | 接口（Interface）  |
| :------- | :----------------------- | :----------------- |
| **用途** | 提供元数据               | 定义行为契约       |
| **方法** | 只能有简单属性（无逻辑） | 可以有具体方法实现 |
| **继承** | 通过 `@Inherited` 控制   | 类必须实现所有方法 |

------

### **六、最佳实践**

1. **明确目标**：注解应用于元数据描述，而非业务逻辑。
2. **合理命名**：注解名应清晰表达用途（如 `@Nullable`, `@Transactional`）。
3. **避免过度使用**：过多注解会降低代码可读性。

通过注解，Java 实现了声明式编程（如 Spring 的 `@Transactional`），极大简化了开发。掌握注解是深入 Java 生态系统的关键！
